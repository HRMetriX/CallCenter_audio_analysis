# CallCenter Audio Analysis Pipeline

Автоматизированный пайплайн для расшифровки двухканальных записей телефонных разговоров call-центра с использованием моделей GigaAM v3 и Silero VAD.

## Особенности
- Разделение спикеров: Автоматическое разделение стерео-записи на каналы (оператор/клиент).
- Детекция речи: Использование Silero VAD для отсечения тишины и фонового шума.
- Точная транскрипция: Модель GigaAM v3_e2e_rnnt обеспечивает распознавание с пунктуацией и нормализацией текста.
- Пословная разметка: Экспорт таймстампов для каждого слова.
- Идемпотентность: Встроенный реестр позволяет безопасно перезапускать обработку больших объемов данных, пропуская уже готовые файлы.
- Экономия ресурсов: Обработка аудио происходит in-memory, без сохранения тысяч промежуточных WAV-файлов.

## Технологический стек
- Python 3.10+
- GigaAM v3 (ASR)
- Silero VAD (Voice Activity Detection)
- ffmpeg (предобработка аудио)
- PyTorch, NumPy, Soundfile

## Установка

1. Клонируйте репозиторий:
   git clone https://github.com/HRMetriX/CallCenter_audio_analysis.git
   cd CallCenter_audio_analysis

2. Установите зависимости через Poetry:
   poetry install

3. Убедитесь, что ffmpeg установлен в системе и добавлен в PATH.

## Использование

Обработка одного файла:
poetry run python main.py --file data/in/call_recording.ogg

Пакетная обработка папки:
poetry run python main.py --dir data/in

Принудительный перезапуск (игнорирование реестра):
poetry run python main.py --dir data/in --force

## Структура выходных данных
Результаты сохраняются в папку data/out/<имя_файла>/:
- <name>_transcript.json: Полная статистика, пословная транскрипция и метаданные.
- <name>_dialogue.json: Хронологическая последовательность реплик диалога.
